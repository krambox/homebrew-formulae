# Krambox Formulae

## How do I install these formulae?

`brew install krambox/formulae/<formula>`

Or `brew tap krambox/formulae` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "krambox/formulae"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
